# Le Relais de la Marche

Site de la guilde (West Marches).

- `index.html` : la page, avec les onglets Carte, Bastion, Marchand et Butin.
- `data/` : un fichier JSON par onglet. Pour mettre le site à jour, remplacez le fichier concerné puis validez (Commit changes).

La carte ne contient que les cases révélées : aucune donnée secrète n'est publiée ici.
