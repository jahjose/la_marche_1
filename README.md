# Les Chroniques de Valgris

Site de la guilde des Elmarith (campagne West Marches, D&D 2024).

- index.html : le site (9 onglets).
- assets/ : les images du site (ne pas modifier).
- data/ : les données de la campagne (un fichier JSON par onglet + l'image de la carte).
  Pour mettre le site à jour, déposez les nouveaux fichiers dans data/ (ils remplacent les anciens), puis validez (Commit changes).

Le site ne contient que ce que les joueurs ont découvert : aucune donnée secrète.
